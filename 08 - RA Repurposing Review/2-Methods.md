# طريقة البحث

> ازاي تستخدم الملف ده:
> 1. اقرا الفكرة بالعربي.
> 2. اكتب الجملة بالإنجليزي بأسلوبك في ملف اليوم، باستخدام الكلمات اللي في الصندوق.
> 3. القسم ده مالوش مراجع، انت بس بتوصف احنا دوّرنا ازاي. كل الأرقام من البحث اللي عملناه فعلًا.

## الفقرة الأولى: البحث والاختيار

### جملة 1
قول نوع المراجعة: مراجعة سردية، بس البحث فيها كان منظّم.
```
narrative review
structured literature search
```
(الجملة دي مالهاش مرجع)

### جملة 2
دوّرنا في تلات قواعد بيانات، والتالتة عشان نلحق المجلات المحلية والإقليمية كمان.
```
PubMed/MEDLINE, Europe PMC, OpenAlex
OpenAlex: to cover regional journals (e.g., EKB)
```
(الجملة دي مالهاش مرجع)

### جملة 3
آخر مرة دوّرنا كانت في سبتمبر ٢٠٢٦.
```
last search: September 2026
```
(الجملة دي مالهاش مرجع)

### جملة 4
كلمات البحث: اسم الدوا أو المجموعة، مع الروماتويد أو نماذج التهاب المفاصل في الحيوانات.
```
drug or class name (metformin, statins, pioglitazone, fenofibrate,
GLP-1 receptor agonists, SGLT2 inhibitors, angiotensin receptor blockers)
AND ("rheumatoid arthritis" OR "collagen-induced arthritis"
OR "adjuvant-induced arthritis")
```
(الجملة دي مالهاش مرجع)

### جملة 5
دخّلنا الأبحاث الأصلية بكل أنواعها، بالإنجليزي، اللي نصها الكامل متاح ببلاش، من ٢٠٠٥ لـ ٢٠٢٦، مع تركيز على آخر خمس سنين.
```
included: original studies (in vitro, animal, observational, clinical trials)
English, free full text, 2005–2026
focus on the last five years
```
(الجملة دي مالهاش مرجع)

### جملة 6
استبعدنا ملخصات المؤتمرات، والأبحاث اللي مالهاش نص كامل، والأبحاث المسحوبة.
```
excluded: conference abstracts
studies without full text
retracted articles
```
(الجملة دي مالهاش مرجع)

### جملة 7
لكل دوا اخترنا أقوى الدراسات: التجارب العشوائية والدراسات الكبيرة على المرضى الأول، وبعدها دراسات الحيوانات اللي بتشرح الآلية.
```
for each drug: strongest studies selected
priority: RCTs, large cohorts,
animal studies with mechanistic data
```
(الجملة دي مالهاش مرجع)

### جملة 8 (اختيارية)
عدد النتايج في PubMed لكل دوا (أبحاث أصلية، نص كامل ببلاش).
```
PubMed hits (free full text, primary studies):
metformin 36, statins 165, pioglitazone 24, fenofibrate 10,
GLP-1 RA 15, SGLT2i 8, ARBs 17
```
(الجملة دي مالهاش مرجع)
